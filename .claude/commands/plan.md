# Plan - 계획 모드 가이드

> "좋은 계획이 성공의 90%"

Plan 모드로 전환하여 작업을 계획합니다.

## Plan Mode 진입

**Shift + Tab** 2회 입력으로 Plan 모드 진입

## 언제 Plan Mode를 사용하나요?

### 반드시 사용
- [ ] 새로운 IDP 컴포넌트 추가
- [ ] 기존 스크립트 대규모 수정
- [ ] GitOps 앱 구조 변경
- [ ] 버전 업그레이드 (특히 breaking changes)
- [ ] 네트워크/스토리지 구조 변경

### 선택적 사용
- [ ] 단순 버그 수정
- [ ] 문서 업데이트
- [ ] 설정값 변경

## Plan Mode 워크플로우

```
1. Shift+Tab 2회 → Plan 모드 진입
   ↓
2. 요구사항 정의
   - 무엇을 해야 하는가?
   - 왜 필요한가?
   - 영향 범위는?
   ↓
3. 현재 상태 분석
   - 관련 파일 목록
   - 의존성 확인
   - 잠재적 충돌
   ↓
4. 실행 계획 수립
   - 단계별 작업 목록
   - 각 단계 검증 방법
   - 롤백 계획
   ↓
5. 계획 확정
   ↓
6. 자동 수락 모드로 전환
   ↓
7. 한 번에 실행
```

## 계획 템플릿

```markdown
## 목표
[1-2줄로 목표 설명]

## 영향 범위
- 수정 파일:
- 의존성:
- 테스트 필요:

## 실행 단계
1. [ ] 단계 1
2. [ ] 단계 2
3. [ ] 검증

## 검증 방법
- [ ] 문법 검사
- [ ] 클러스터 테스트
- [ ] ArgoCD 동기화 확인

## 롤백 계획
[문제 발생 시 복구 방법]
```

## 사용법

이 명령어는 Plan 모드 사용 가이드를 표시합니다.
실제 Plan 모드 진입은 **Shift+Tab 2회**입니다.
