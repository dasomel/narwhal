# Plan - 계획 모드 가이드

> "좋은 계획이 성공의 90%"

## Plan Mode 진입

**Shift + Tab** 2회 입력으로 Plan 모드 진입

## 언제 사용하나요?

### 반드시 사용
- 새로운 IDP 컴포넌트 추가
- 기존 스크립트 대규모 수정
- GitOps 앱 구조 변경
- 버전 업그레이드 (특히 breaking changes)
- 네트워크/스토리지 구조 변경

### 선택적 사용
- 단순 버그 수정
- 문서 업데이트
- 설정값 변경

## 계획 템플릿

```markdown
## 목표
[1-2줄로 목표 설명]

## 영향 범위
- 수정 파일:
- 의존성:

## 실행 단계
1. [ ] 단계 1
2. [ ] 단계 2
3. [ ] 검증

## 검증 방법
- [ ] 문법 검사
- [ ] 클러스터 테스트

## 롤백 계획
[문제 발생 시 복구 방법]
```
